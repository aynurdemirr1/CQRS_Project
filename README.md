🚗 ASP.NET Core 9.0 & CQRS ile Araç Kiralama Sistemi

Bu repository, ASP.NET Core 9.0 ve CQRS mimarisi kullanılarak geliştirilmiş bir araç kiralama case projesini içermektedir.

Projenin amacı yalnızca bir CRUD uygulaması geliştirmek değil;
gerçek hayata yakın senaryolar, harici API entegrasyonları ve
yapay zeka destekli özellikler ile sürdürülebilir bir mimari oluşturmaktır.

📌 Genel Yapı

🔹 Mimari → CQRS ile okuma ve yazma operasyonları ayrıştırıldı
🔹 Veritabanı → MS SQL Server üzerinde ilişkisel tablolar tasarlandı
🔹 UI Yapısı → ViewComponent kullanılarak tekrar eden alanlar izole edildi
🔹 API Entegrasyonları → Lokasyon, mesafe ve yakıt verileri dinamik olarak alındı

🚀 Öne Çıkan Özellikler

🚗 Tarih aralığına göre müsait araç listeleme
📍 Pick-Up / Drop-Off seçimine göre mesafe hesaplama
⛽ Ortalama yakıt tüketimi üzerinden tahmini maliyet gösterimi
🤖 AI destekli araç öneri asistanı
📧 İletişim formu sonrası otomatik yapay zeka mail yanıtı
🛠 Admin paneli üzerinden araç, kategori, rezervasyon ve lokasyon yönetimi

🛠 Kullanılan Teknolojiler

ASP.NET Core 9.0

CQRS Pattern

Entity Framework Core

MS SQL Server

RapidAPI

Gemini AI

Bootstrap 5
